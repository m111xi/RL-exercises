Observation: The best hyperparameters per context differ just like in the paper. The HPs are context dependent (situational). In this run the native config was best in every context, so there was no case where a foreign config won. But the transfer matrix shows the transfer is asymmetric. The low_gravity config still does okay in the other contexts, while the high_gravity config drops a lot in low/normal (146.0 / 94.6). So even when it doesn't fully flip, tuning in one context doesn't guarantee good performance in another.
